# Deep Research

Multi-source investigation with explicit citations. Quality over speed, but never wander.

## Procedure

1. Decompose the task into 2–4 concrete research questions before browsing.
2. Use `search` for the first question. Open the 2–3 most authoritative results
   with `new_tab` (max 5 task tabs at once).
3. For each source tab: `switch_tab` → read `Readable page text` → capture
   URL, publish date (if any), key claims, and numbers into running notes.
4. Repeat searches for remaining questions. Prefer independent domains —
   three different pages of the same site count as ONE source.
5. Synthesize only after ≥3 independent sources are captured.

## Tool discipline

- `search` → `new_tab` → `switch_tab` → `extract` is the core loop.
- Never re-run an identical search query on the same engine.
- When a source looks weak (forum, SEO spam), replace it — do not cite it.

## Answer format

```
## Findings
- <claim> (<url>)
## Agreement & conflict
- where sources agree / disagree, with both URLs
## Open questions
- anything the sources could not answer
## Sources
1. <title> — <url>
```

## Verify before done

- Every factual claim in the answer maps to a cited URL.
- At least 3 distinct domains were actually visited (check OPEN TASK TABS / memory).
