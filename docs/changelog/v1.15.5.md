# v1.15.5: About page (UI only)

Settings gains an About entry: the real running version read from
`chrome.runtime.getManifest()`, a changelog summarizing v1.14 through v1.15.5,
project details for problem statement 26171 and ISRO, and one-click copy of
build information for bug reports.

The version chip reflects the loaded build, so a stale unpacked copy can no
longer pass for the current one. No detection, redaction or loop file changed in
this release; the privacy pipeline is byte-identical to v1.15.4.

Verification: new `scripts/test_about_page.mjs` 21/21 on the real unpacked
extension, covering manifest version parity, logo load, changelog order, the
hidden save button, the copy-build-info outcome and zero page errors. The
v1.15.1 panel suite still passes 28/28.
