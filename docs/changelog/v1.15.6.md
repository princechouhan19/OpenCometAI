# v1.15.6: final answers and profile data

A field report on a summarize task against a thinking backend: the loop
sanitized, asked the model once, and finished "in 1 steps" with a bare "Task
complete." The summary was never delivered.

## Root cause

The privacy decision prompt had no answer channel, meaning no `message` field
on the done action and no rule for information tasks. The loop dropped the
payload at `is_complete`, and `AGENT_DONE` reached the panel without an `answer`,
so the result card fell back to a hardcoded string.

## 1. An answer channel, end to end

The decision contract gains `action.message`, described as the complete final
answer and required for done on information and summary tasks, plus an
information-tasks rule that lifts the page-state verification requirement for
summarize and question answering.

`privacy-loop.js` extracts `finalAnswer` (message, then summary, then text, then
`plan.answer`), emits a "Final answer ready (N chars)" step and ships it in the
DONE summary. `sw.js` broadcasts `AGENT_DONE` with `answer` and writes it to
history. The side panel renders `msg.answer`, then `summary.finalAnswer`, then
`finalThought` in the result card, preserving markdown.

## 2. Profile data reaching the agent

Settings, Profile gains Custom info: user-defined label and value rows with add,
remove and persistence, plus an empty-state hint.

Saved rows reach every decision path. The privacy loop appends a trusted user
profile trailer (fixed fields plus custom rows, length-capped) after the
outbound secret scan, the same channel the summarize path already used, so
page-content gate semantics are unchanged. The standard loop's `formatProfile`
renders custom rows, and the summarize prompt formats them explicitly rather
than printing `[object Object]`.

## 3. Verification

New `scripts/test_v1156_answers_profile.mjs` 20/20 on the real unpacked
extension with a scripted mock model: a summarize run renders the full bullet
answer in the card, the transcript and history; the decision prompt carries the
contract; a user profile block with custom rows ("Age: 21", "Shirt size: M")
reaches the model and the agent answers "What is my age?" from it; and the
profile UI round-trips through render, add, save, storage, reload and remove.
The About chip tracks v1.15.6. The v1.15.1 panel suite (28/28) and About (21/21)
remain green, with the standing privacy and benchmark suites in
`scripts/package_v1156.sh`.
