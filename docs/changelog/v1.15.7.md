# v1.15.7: the firewall stops killing summarize on secret-shaped pages

Field report on privacy mode over a long chat page: the run died before the
first model call with "Privacy firewall BLOCKED the network request:
secret-shaped text (API key / credentials / password assignment) survived
sanitization", followed by a 0 ms blocked turn and an ask-user dead end.

## Root cause

The outbound gate probe and the decision prompt read the pipeline's
`sanitizedDomText`, whose text-PII scan truncates at 8000 characters and passes
text through raw on a scan error. A key-shaped fragment deeper in the page
tripped the sweep, and the old last-line policy aborted the whole decision turn.

## 1. Envelope-first text

The gate probe and the decision prompt now read the firewall envelope's
canonical `privacy.sanitizedText`: a final PII sweep over 16000 characters plus
smuggler-character stripping. That is the rule the companion-server path has
followed since v1.14. The fuzz and security suites already feed the prompt the
envelope text, so no benchmark number changes.

## 2. Redact and verify

The last line of defence upgrades from blocking the turn to masking the
fragment, re-verifying, and shipping clean text. A new firewall export,
`maskSecretShapedText()`, replaces every secret-sweep match with a sweep-inert
`[REDACTED:secret]` marker.

`scrubOutboundDecisionText()` masks the task, every history string and both
page-text copies before any wire string is assembled, and the assembled prompt
is masked and re-scanned. The guarantee is preserved: anything masking cannot
clean still blocks, and the trusted profile trailer stays outside the sweep, as
designed in v1.15.6.

## 3. Debuggable blocks

Gate refusals now name the offending field and pattern IDs in the console and in
the ask-user message. They never name values.

## 4. Verification

New `scripts/test_v1157_secret_sweep.mjs` 22/22.

Part A, in Node: the field failure reproduced at unit level and the fix proven,
covering the envelope-first gate, masking across all nine families, prose left
untouched, self-healing, scrub semantics and diagnostics.

Part B, on the real unpacked extension: summarizing a page carrying five
key-shaped strings past character 8000
(`OpenCometBench/e2e/pages/secret-tail.html`) completes with the bullet answer
in the result card, the gate never fires, and no raw secret reaches the mock
backend. Standing suites stay green through `package_v1157.sh`.
