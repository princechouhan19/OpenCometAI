# v1.15.1: human in the loop, honest no-ops

Driven by field run 2 (6 steps, 194 s, YouTube, qwen3-vl) and user bug reports.

**Stop button.** The privacy flow double-wrapped its `AGENT_DONE` and
`AGENT_ERROR` broadcasts, so the sidebar never learned the task had finished.
The Stop button stayed visible after "Task complete", and late clicks produced
"Stopping…" and "Unable to add context right now" noise.

**Ask before acting.** With the composer set to ask before acting, every
privacy-run action, primary or queued, waits for an in-chat approval card with
Allow once, Skip and Stop task. Skip writes a history entry and asks the model
again; Stop aborts. The choice survives a panel reload.

**Live context.** Text sent while a task runs is drained into the next decision
prompt as high-priority user context, PII-swept and consumed once.

**Media no-ops.** A media play on an already playing video now reports a
verified no-op ("ALREADY IN STATE", ACTION_VERIFIED) instead of a misleading
NO CHANGE. E2E-MOCK verifiedActionRatio moves from 0.952 to 1.000.

**Console visibility.** Every model call logs `[VLM-REQ]` (full prompt text and
image metadata, pixels never dumped), `[VLM-RAW]` (model text before parsing)
and `[VLM-RES]` (the parsed response).

Also: long model names ellipsize in the model pill and dropdown, the duplicate
settings icon in the top right is gone, and a real-browser regression suite
(`scripts/test_v1151_panel.mjs`, 28 checks) pins all of it.
