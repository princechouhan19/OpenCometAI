# v1.14: privacy firewall and fail-closed network gate

This is the architecture note for the firewall section that used to live in the
README. The single-boundary firewall shipped during the v1.14 rounds, alongside
the detector memos; the v1.14.1 YOLO and face memo pattern is what the v1.16.0
OCR memo later mirrors. Per-version narratives start at v1.15.0.

`src/lib/privacy-firewall.js` is the one boundary every network-bound screen
context passes through:

```
raw screen → runPrivacyPipeline → sanitizeScreenContext() → validateSanitizedPayload()
                                                   pass → send sanitized only
                                                   fail → PrivacyBlockedError (nothing sent)
```

All three decision paths are gated: on-device, direct provider and companion
server. The assembled prompt is additionally swept for secret-shaped text
immediately before transmission. A redaction engine crash degrades to a blank
1×1 frame, never raw pixels.
