# v1.30.0: per-test latency everywhere, ROI rescan activation

Released 2026-10-05. Benchmark infrastructure plus a perception-pipeline
latency optimisation.

Verification: `scripts/test_v1300_latency_roi.mjs` 67/67, OpenCometBench 6/6
pass, and quality metrics byte-identical to v1.29.0.

## Per-test latency in every benchmark

Before this release only tier-level wall time existed, plus percentile summaries
in the browser and end-to-end tiers. The six Node suites had no per-test timing
at all.

- **`OpenCometBench/latency.js`** provides `timed()` for per-case wall time,
  `latencyStats()` for count, minimum, p50, mean, p90, p95, maximum and total,
  and `roundSamples()`. The percentile method matches the runners' `pct()`,
  using a sorted array, a `floor(q·n)` index and clamping, so numbers are
  comparable across tiers. Empty or non-numeric sets report `n=0`; a missing
  measurement is never reported as zero.
- **All six unit suites are timed per case**: privacy for every corpus case,
  redaction for every analytic step with a `+stageMs` breakdown, visual context
  for every classification and worst-case gate decision, security for every
  test, fuzz for every case's full outbound path, and server validation for
  every test.
- **The adversarial end-to-end runner** times every case into `latencyMs`, shown
  in the live table and stored in the report.
- **`run-all.js`** prints a latency line per suite, and `--json` carries the
  full per-case `samplesMs[]` arrays, 815 samples in total.

## ROI rescan wired into the OCR stage

`src/lib/roi-diff.js`, pure, dependency-free and unit-testable, had been
complete but unused since it was written. It now drives partial rescanning in
the OCR stage.

- `privacy-filter.js` keeps a fingerprints-only chain state (`_roiState`): block
  fingerprints from mean, variance and gradient energies over a 96×54 grayscale
  proxy, plus the OCR regions valid on those pixels. No pixels are retained, and
  the statistics cannot reconstruct the screen.
- On an OCR memo miss, `planRoiRescan()` diffs fingerprints and chooses between
  a full and a region-only rescan. Every guard fails toward a full scan: first
  sight, URL change, capture dimensions change, changed ratio over the cap, the
  periodic full-scan cap, the coverage cap, and any computation error.
- Region mode re-OCRs only the changed regions through the strict
  `scanImagePiiRegionsRoi` in `ocr-pii.js`, which uses ×2 upscaled crops and
  throws on decode failure or zero scanned regions so the caller degrades to a
  full scan. Previous regions entirely outside every scanned region are kept;
  stale boxes never survive on changed pixels.
- When `changedCount` is 0, as happens on re-encoding noise during an
  exact-string memo miss, all previous regions are reused and no scan runs.
- Failed or skipped scans reset the chain. `cfg.roiRescan`, on by default, is
  the fail-safe switch. Telemetry lands in `stats.roi`, with `roiMode=roi` or
  `roiMode=full` logged.

Measured decision overhead in Node for fingerprints, diff, plan and region
planning is 0.095 ms per frame, four orders of magnitude below the reference
full-page OCR leg of about 3402 ms. End-to-end region-mode timing lands in
`stats.roi.scanMs` on every live frame; browser-tier before and after numbers
belong to the browser tier, since the unit tier does not run the OCR engine.

## Quality comparison, v1.29.0 to v1.30.0

Every quality metric is identical. The release adds measurement and a reuse
path; it does not touch detector semantics.

| Suite | v1.29.0 | v1.30.0 | Change |
|---|---|---|---|
| PII detection | P=1, R=1, F1=1 (366 true positives) | Same | None |
| Redaction | Coverage 0.983, IoU 0.938, over-redaction 5.86% | Same | None |
| Visual context | Accuracy 1 (11/11), gate 4/4 | Same | None |
| Security suite | 29/29 | 29/29 | None |
| Fuzz | 0 leaks in 216 | 0 leaks in 216 | None |
| Server validation | 25/25 | 25/25 | None |

What improved: benchmark observability, from tier wall time only to 815
individually timed cases with full sample arrays, and the changed-frame
perception path, from full-page re-OCR on every memo miss to region-level reuse.
